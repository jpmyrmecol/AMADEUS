# Without direction estimation

前後を安定して区別できない対象や、頭部方向が不要な解析に使用します。
Easy TrackingまたはAdvanced Trackingで **Without direction estimation** をオンにしてください。
初期値はオフです。**ベータ版機能のため、追跡結果を確認して使用してください。**

## 推定する情報

- OBBと個体IDを推定します。OBBの回転は形状の情報として保持しますが、頭尾や頭部方向は推定しません。
- 静止、短い軌跡、移動方向の不確定、OBBの縦横比だけを理由に個体を除外しません。重なりや外れ値などの品質判定は維持します。
- 固定個体数・可変個体数のどちらでも使用できます。
- 結果動画には方向矢印やOBBの三角形を描画しません。

## 出力と再利用

出力は元のセッションの `without_direction_estimation/` 以下に保存されます。
通常モードとは設定、学習データ、重み、追跡結果を分けて保存し、元の設定ファイルは書き換えません。

最終CSVは `frame, cx0, cy0, w0, h0, ...` 形式で、`heading` 列はありません。
OBBの頂点は中間CSVに残ります。

このモードで作成した学習データと重みを使用してください。通常の方向クラス付きモデルは使用できません。
工程をスキップして再利用する場合は、必要な成果物がこのモードの出力先にあることを確認してください。
独自の `CREATE_DATASET_SOURCE_DIRS` を設定していた場合は、空にしてこのモード用のデータセットを生成してください。

操作方法と制約は[日本語マニュアル](https://amadeus.jpmyrmecol.com/jp/manual.html#without-direction-estimation)を参照してください。
